# 📑 PDF Studio (v1.0.0)

> **100% 브라우저 로컬 구동! 서버 없는 초경량 고품질 PDF 제작 & 스마트 편집 웹 스튜디오**  
> GitHub Pages 정적 웹 호스팅을 통해 완전 무료로 영구 배포할 수 있는 클라이언트 전용 PDF 툴킷입니다.

---

## 🌟 핵심 특장점 & 해결 과제

### 1. ⚡ 대량 이미지 초고속 결합 & 완벽한 자연어 정렬 (순서 꼬임 방지)
- **문제점**: 웹 브라우저에서 수십~수백 장의 스캔 이미지를 일괄 업로드하면 용량이 작은 파일이 먼저 로드되어 페이지 순서가 뒤섞이는 비동기 레이스 컨디션(Race Condition)이 흔히 발생합니다.
- **해결책**:
  - `Intl.Collator` 기반의 **자연어 영숫자 정렬**(Natural Alphanumeric Sorting: `1, 2, ..., 9, 10, 11`)을 거친 후, `new Array(total)` 고정 슬롯에 엄격하게 순차 매핑하여 **대량 업로드 시에도 순서 뒤틀림이 0%**입니다.
  - 고해상도 원본은 Blob 레퍼런스로 안전하게 유지하고 작업대에는 380px 다운샘플링 캔버스 썸네일을 렌더링하여 **수백 장을 한 번에 올려도 메모리가 쾌적**합니다.

### 2. 🛡️ 삼성노트 호환 무음 보안 해제 (Silent Security Stripper)
- **문제점**: 일부 관공서, 수험서, 웹 뷰어에서 내려받은 PDF는 비밀번호 없이 열람은 가능하지만 인쇄 권한이나 주석 추가가 잠겨 있어, **삼성노트(Samsung Notes)나 태블릿 필기 앱에서 불러올 수 없는 치명적인 문제**가 있습니다.
- **해결책**:
  - PDF.js 및 PDF-Lib의 보안 우회 로더를 통해 열람 가능한 모든 페이지 콘텐츠를 분해 추출한 뒤, 암호화 딕셔너리(`Encrypt Dictionary`)가 전무한 **완전히 깨끗한 새 표준 PDF로 재조립**합니다.
  - 별도의 복잡한 절차 없이 **그냥 열고 다시 저장하는 것만으로도 삼성노트에서 자유롭게 필기 가능한 클린 PDF로 변환**됩니다.

### 3. 🧩 지능형 페이지 재정렬 & 그룹 기반 분할 (JSZip 압축 일괄 다운로드)
- **자유로운 편집**: 드래그 앤 드롭으로 카드 위치 이동, 연속 범위 선택(Shift+Click), 선택 반전, 90도 단위 회전, 특정 페이지 삭제.
- **실시간 순번 배지**: 원본 출처 정보(`스캔_001.png · p.1`)와 재정렬된 최종 인쇄 순번(`[#1]`, `[#2]`)을 이원화 표시.
- **그룹별 자동 분할**:
  - 교재나 스캔본을 [문제편], [해설편], [정답표] 등의 그룹으로 묶어두면, **`📦 그룹별 분할 PDF` 클릭 한 번에 각 그룹별 독립 PDF를 자동 생성하고 `.zip` 압축 파일로 패키징**하여 일괄 내려받을 수 있습니다.
  - 사이드바에서 원하는 그룹만 골라 단독 PDF(`[💾]`)로 즉시 추출할 수도 있습니다.

### 4. 🎨 표지 전용 모드 & 다중 판형 맞춤 (A4 / B5 / Letter / 원본)
- **0번 전용 표지 지정**: `⭐ 표지 추가` 버튼을 통해 맨 앞 1번에 표지 이미지를 즉시 삽입하고, 본문과 달리 여백 없이 꽉 채우는 **전면 채우기(Full Bleed Cover Fit)** 지원.
- **다양한 판형 규격**:
  - **A4 표준 규격** (595 × 842 pt): 일반 문서, 보고서
  - **B5 수험서 규격** (499 × 709 pt): 시중 문제집, 참고서, 교재 판형 최적화
  - **US Letter 규격** (612 × 792 pt): 북미 표준 규격
  - **원본 1:1 해상도 유지**: 이미지 픽셀 크기 100% 보존
- **문서 메타데이터 주입**: 제목(파일명 기반 1-클릭 자동완성), 작성자, 주제, 검색 키워드 표준 PDF 헤더에 주입.

## 🔒 100% 오프라인 & 프라이버시 원칙 (Zero-Server)

- 사용자가 업로드하는 이미지와 PDF 파일은 **단 1바이트도 외부 서버로 전송되지 않습니다**.
- 모든 연산은 사용자의 웹 브라우저 내부(JavaScript, HTML5 Canvas, WebAssembly)에서 100% 로컬 처리됩니다.
- 오프라인 환경(비행기 모드, 인터넷 단절 환경)에서도 완벽하게 작동합니다.

## 🚀 GitHub Pages 배포 가이드 (완전 무료 호스팅)

이 프로젝트는 별도의 백엔드 서버나 빌드 과정(`npm run build` 등)이 필요 없는 **순수 정적 웹 앱**이므로, GitHub 저장소에 올리는 즉시 전 세계 어디서나 접속 가능한 웹 서비스가 됩니다.

### 단계별 배포 순서:
1. **GitHub 저장소 생성**:
   - [GitHub.com](https://github.com)에 로그인 후 `New repository`를 클릭합니다.
   - 저장소 이름(예: `pdf-studio`)을 입력하고 **Public**으로 생성합니다.

2. **소스 코드 푸시**:
   - 본 프로젝트 폴더 내의 파일들을 Git으로 커밋하고 푸시합니다.
   ```bash
   git init
   git add .
   git commit -m "feat: PDF Studio v1.0.0 정식 릴리즈"
   git branch -M main
   git remote add origin https://github.com/<사용자이름>/<저장소이름>.git
   git push -u origin main
   ```

3. **GitHub Pages 활성화**:
   - GitHub 저장소 상단 메뉴의 **Settings** 탭 클릭.
   - 좌측 메뉴에서 **Pages** 클릭.
   - **Build and deployment** 섹션의 Source 항목을 `Deploy from a branch`로 설정.
   - Branch: `main` 브랜치 선택, 폴더는 `/ (root)` 선택 후 **Save** 클릭.

4. **배포 완료 및 접속**:
   - 약 1~2분 후 상단에 표시되는 배포 주소(예: `https://<username>.github.io/<repo-name>/`)로 접속하면 배포가 완료됩니다!

별도의 Node.js 설치 없이도 아무 정적 웹 서버에서 실행할 수 있습니다.

```bash
# 옵션 1: npx serve 사용
npx serve .

# 옵션 2: Python 내장 서버 사용
python -m http.server 8080

# 옵션 3: VSCode 사용자
# 'Live Server' 확장 프로그램을 설치한 후 index.html에서 마우스 우클릭 -> "Open with Live Server"
```

## 📱 PWA (프로그레시브 웹 앱) 설치 안내

- **데스크톱 (Chrome / Edge)**: 주소창 우측의 `앱 설치` 아이콘을 누르면 일반 PC 프로그램처럼 바탕화면에 독립 실행 창으로 설치됩니다.
- **모바일 / 태블릿 (Android / iOS)**: 브라우저 메뉴에서 `홈 화면에 추가`를 누르면 스마트폰 및 태블릿 앱처럼 설치되어 전체 화면으로 사용할 수 있습니다.

## 🛠️ 기술 스택 및 구조

- **Frontend Core**: Semantic HTML5, Modern CSS3 (Grid & Flexbox, CSS Custom Properties), Vanilla JavaScript (ES6+)
- **PDF Engine**: 
  - [PDF-Lib v1.17.1](https://pdf-lib.js.org/) (클린 PDF 조립 및 메타데이터 주입)
  - [PDF.js v3.11.174](https://mozilla.github.io/pdf.js/) (PDF 페이지 분해 및 썸네일 고화질 렌더링)
- **Archive Engine**: 
  - [JSZip v3.10.1](https://stuk.github.io/jszip/) (클라이언트 ZIP 압축 패키징)
- **Zero External CDN**: 모든 라이브러리는 `libs/` 디렉터리에 로컬 번들링되어 있어 외부 네트워크 차단 위험이 없습니다.

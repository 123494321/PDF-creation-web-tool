💡 PDF Studio 핵심 기능 및 안내

1. 대량 이미지 순서 보정

비동기 로딩 지연으로 인한 순서 꼬임을 원천 차단하며, '1, 2, ... 10'과 같은 자연어 번호 순서로 자동 배치합니다.

2. 삼성노트 호환 보안 해제

열람은 가능하지만 필기나 주석 작성이 차단된 PDF는 불러온 뒤 바로 [통합 PDF 저장]만 누르면 깨끗한 일반 PDF로 변환됩니다.

3. 그룹화 기반 분할

원하는 페이지들을 선택해 그룹을 지정하면, 각 그룹별로 분할된 PDF 여러 개를 ZIP 파일 하나로 일괄 다운로드할 수 있습니다.

4. 100% 로컬 보안 원칙

모든 데이터는 사용자 브라우저 내부에서만 처리되며, 어떤 파일도 외부 서버로 전송되지 않습니다.
